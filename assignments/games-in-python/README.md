
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a classic Hangman game in Python to practice string handling, loops, conditionals, and user input. This assignment reinforces core programming concepts by creating a game that is both interactive and easy to extend.

## 📝 Tasks

### 🛠️ Create the core game logic

#### Description
Write a Python program that lets a player guess letters in a hidden word. The game should continue until the player correctly guesses the word or runs out of attempts.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list using Python logic
- Display the hidden word as underscores or blanks for each letter
- Accept one letter at a time as input from the player
- Reveal correctly guessed letters in the appropriate positions
- Track the number of incorrect guesses remaining
- End the game when the word is fully guessed or attempts are exhausted
- Display a clear win or lose message at the end

### 🛠️ Improve the player experience

#### Description
Add polish to the game so it feels more interactive and user-friendly while staying easy to read and understand.

#### Requirements
Completed program should:

- Show the current progress after each guess
- Display the remaining attempts in a clear format
- Prevent repeated guesses or handle invalid input gracefully
- Provide friendly feedback for correct and incorrect guesses
- Keep the game loop running until the round ends
- Use clear prompts and readable output messages
